# AqarJo Backend

Backend API for AqarJo, a real estate marketplace. Built with Node.js and
Express.

## Getting started

```
npm install
npm run dev
```

The server starts on `http://localhost:5000` by default (configurable via
`PORT` in `.env`, see `.env.example`).

```
GET /api
→ { "message": "AqarJo API is running" }
```
